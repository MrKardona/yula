# VibraLuna Accesorios

Tienda de accesorios hechos a mano con piedras naturales y significado espiritual: pulseras, collares, aretes y cajitas de regalo con velita aromática. Se filtra por intención, tipo, línea y signo, y el pedido se envía por WhatsApp.

- Productos, precios y número de WhatsApp: `productos.js`
- Significados (colores, flores, símbolos), fases de la luna y artículos del diario lunar: `contenido.js`
- Imágenes de marca y banners: `img/vb/`. Fotos de producto: `img/p/` (generadas con IA, ilustrativas)

Sitio estático, publicado con GitHub Pages.
