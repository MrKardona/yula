# Yulá · Curando tu alma

Tienda de accesorios hechos a mano con piedras naturales: pulseras, collares, aretes y cajitas de regalo. Se filtra por intención, tipo, línea y signo, y el pedido se envía por WhatsApp.

- Para editar productos, precios o el número de WhatsApp: `productos.js`
- Fotos de producto: `img/p/` (generadas con IA, ilustrativas)

Sitio estático, publicado con GitHub Pages.
